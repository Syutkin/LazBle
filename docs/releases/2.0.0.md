# LazBle 2.0.0

LazBle 2.0.0 moves to the public SimpleDelphiBLE 1.3.0 API. It provides
asynchronous discovery, connections, GATT operations, notifications, NUS and
Battery profiles, optional reconnection, and LCL components.

This major release changes the threading, cancellation, and shutdown contracts.

## Dependency and installation

Use Free Pascal 3.2.2 or later and Lazarus for LCL components. Download the
official SimpleDelphiBLE 1.3.0 release and place its contents in LazBle's
`simpledelphible/` directory. The dependency is supplied separately; the whole
directory is ignored by Git.

`LazBle` compiles the official sources directly. Register `lazble.lpk` and,
for LCL applications, `lazblelcl.lpk`. Install `lazblelcldesign.lpk` for the
component palette. A separate binding package is no longer needed.

Native link paths cover Linux x86_64, Windows x86_64, and macOS Intel and
Apple Silicon. Deploy the matching native libraries beside the executable;
for a macOS app bundle, use `Contents/MacOS`.

See the [README](../../README.md#dependencies-and-native-libraries) for the
directory layout, commands, and platform requirements.

## Upgrading from 1.0

- Replace the SimpleBlePascal dependency with the official SimpleDelphiBLE
  distribution. The custom loader and `SIMPLECBLE_LIBRARY_DIR` lookup are removed;
  native libraries are required when the executable starts.
- Create, access, and release LazBle objects on the main thread. Custom backend
  callbacks must also use that thread. Console programs must service
  `CheckSynchronize`; `TLazBleSync` does this while waiting.
- Complete `ShutdownAsync` before freeing active facade or LCL owners. GUI forms
  should await completion through the event loop and defer their final close.
  Use `OnUnconfigureClient` to clear borrowed client/profile references.
- Treat cancellation as a request: started native operations retain their actual
  outcome and effects. `IBleOperation.Timeout`, `lbopTimedOut`, and `lblssTimedOut`
  are removed. A synchronous wait deadline limits waiting, not the operation.
- Use the upstream GATT records and `CanRead`, `CanWriteRequest`,
  `CanWriteCommand`, `CanNotify`, and `CanIndicate`. Descriptor UUIDs are strings.
  Managed service/data snapshots are read-only; copy arrays before changing them.
- Wait for subscription readiness before consuming notifications. Unsubscribe
  stops local delivery immediately; cleanup failures remain visible on the token
  and disconnect the affected session.
- Determine success from the operation state. Error code 0 and empty text can
  still represent failure. Custom backends report shutdown failure through
  `TLazBleBackendEvent.ShutdownFailed`.
- Use `DiagnosticInfo` for binding, backend, native version, adapter, and
  availability details. Legacy loader warning fields are removed.
